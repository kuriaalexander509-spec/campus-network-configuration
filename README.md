# Campus Network Configuration

## Project Overview

This project is a simulated campus network designed and configured using Cisco Packet Tracer.

The network demonstrates how different departments and devices can communicate through a structured and segmented network infrastructure.

## Technologies Used

- Cisco Packet Tracer
- Cisco Routers
- Cisco Switches
- VLANs
- Inter-VLAN Routing
- DHCP
- IP Addressing
- Wireless Networking

## Network Features

- VLAN configuration
- Inter-VLAN routing
- IP address configuration
- DHCP configuration
- Router and switch configuration
- Network connectivity testing
- Wireless network connectivity

## Project File

The main Cisco Packet Tracer project file is:

`CISCO PROJECT.pkt`

Download the `.pkt` file and open it using Cisco Packet Tracer to examine the network configuration.

## Purpose

The purpose of this project was to gain practical experience in designing, configuring, and troubleshooting computer networks using Cisco networking technologies.
